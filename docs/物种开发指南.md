# 物种开发指南

本文说明怎样给"万物皆可撸"加一个新物种（species），以及引擎里有哪些现成的零件。

## 1. 总体约定

- **视角**：俯视视角（top-down view），动物趴着（prone）。世界坐标里头朝左（-x），尾巴朝右（+x），y 向下。
- **镜头**：`App.layout()` 按 `Creature.frame` 自动缩放并居中。竖屏时镜头转 -90°：动物竖着趴，头在屏幕下方、脸是正的。不要假设屏幕方向。
- **单位**：世界单位约等于横屏桌面上的 1 CSS 像素。猫的身体长约 420、宽约 230，新物种按"真实大小感"定尺寸（仓鼠小、老虎大），镜头会自动框住。
- **画风**：写实。动物是 AI 生成的俯视照片，用 WebGL 网格形变（见第 5 节）；光从左上方来。声音仍全部实时合成，不引用音频文件。早期的卡通零件（`Part`、`FurField`、`ProneRig` 等）还在仓库里，但目前没有物种在用。
- **手感第一**：手的每个动作都要有反馈——视觉（毛发弯曲、形变、表情）和听觉（摩擦声、叫声）。反馈要即时、柔和、有弹性（用弹簧，不用线性插值）。

## 3. 接口

```ts
interface Species {
  id: string; name: string;
  variants?: Variant[];             // 毛色等变体，底部栏上方显示色块
  icon(g, size): void;              // 画头像，size×size 像素
  create(fx: Fx, variant?: string): Creature;
}

interface Creature {
  frame: Bounds;                    // 镜头框住的世界范围
  joy: number;                      // 0..1，开心程度（驱动呼噜等持续声）
  hit(x, y): Contact | null;        // 命中区域 { zone, material, grain? }
  update(f: Frame): void;           // 每帧：f.hand、f.contact、f.touch、f.dt
  background(g, v): void;           // 画布已是世界坐标；常用 Backdrop
  draw(g, v): void;                 // 画在手下面
  drawOver?(g, v): void;            // 画在手上面（抱住手的爪子、合上的嘴）
  attachAudio?(): void;             // 音频就绪后建循环声（Bed）
  dispose(): void;                  // 停掉循环声
}
```

`Frame.hand` 的要点：`touching`（贴在动物身上）、`speed`（世界单位/秒）、`pressure`（鼠标悬停 0.55、按下 1）、`tap`（本帧轻拍）、`scratch`（0..1 挠痒）。`Frame.touch` 直接传给 `FurField.update`。

`Fx`：`au`（音频）、`particles`、`hand`（`kick(dx, dy)` 抽手冲量，`shiver` 发抖）、`warp`、`shake(amount)`、`vibrate(ms)`。

`Contact.material` 决定摩擦声：`fur`（长毛）、`short`（短毛）、`spine`（刺）、`scale`（鳞片）、`skin`（光滑皮肤，吱吱声）。

## 4. 常用做法

- **部件**：`new Part({ outline, zone, paint })`。`outline` 是局部坐标的闭合点列；`paint(g, path, bounds)` 只在建纹理时调用一次，在里面画底色、花纹、`shade()`、`furNoise()`。每帧先设 `part.m.set(x, y, rot, sx, sy, px, py)`（px/py 为枢轴，需与 x/y 相同才不平移），再 `part.update(warp)`，最后 `part.draw(g)`。
- **毛发**：`new FurField(partHost(part), seedPart(part, {...}), { width })`。刺用 `{ kind: 'spine', tip: '#fff', freq: 9, ruffle: 0 }`；`field.bristle = 0..1` 让刺竖起。逆毛会留下"乱毛反光"，`field.messiness` 可用来判断被逆毛了。
- **心情**：`mood.update(f, score)`，score 为正表示喜欢。`speedLike(speed, lo, hi)` 评价手速。用 `Every` 控制冒爱心的节奏。
- **声音**：一次性声音直接调 `tone/noise/voice/sfx.*`，调用前检查 `fx.au.ready`。持续声（呼噜、喘气）在 `attachAudio` 里建 `Bed`，每帧 `bed.set(level)`。音量保守：单个音效增益通常 0.1–0.3。
- **背景**：`new Backdrop((g, area) => …)`，在 `background()` 里 `backdrop.draw(g, v)`。需要动画的背景（水面）直接每帧画，控制开销。

## 5. 写实物种

素材制作见 [写实素材管线](写实素材管线.md)。所有写实物种共用 `PhotoPet`（`src/pets/photo/photoPet.ts`），每个物种只写一份 `PhotoDef`（`src/pets/photo/species.ts`），声音在 `src/pets/photo/voices.ts`，地面在 `src/pets/photo/grounds.ts`。

`PhotoDef` 的要点：

| 字段 | 作用 |
| --- | --- |
| `rig` | 骨架标注（图片像素）：鼻尖、颈部枢轴、脊线 y、头骨过渡、头部范围、胸背软组织、耳朵、尾巴折线 |
| `scale` | 世界单位/图片像素。手的大小固定（`handSize`），所以它决定动物相对手有多大：刺猬 0.5、猫 1、老虎 2.8、虎鲸 3.6 |
| `give` | 柔软度，猫为 1。缩放拖动和下陷。硬度顺序：仙人球 0.03 > 鳄鱼 0.1 > 虎鲸 0.3 > 刺猬 0.4 > 带毛的动物 |
| `fur` | 没有毛（鳞片、鲸鱼皮、仙人球）设为 `false`，不做炸毛 |
| `zone` | 命中区域（图片像素 → 区域名）；`materialOf` 可给个别区域换材质（花盆） |
| `temper` | 各区域喜好、手速喜好、逆毛扣分、喜欢被挠的区域 |
| `voice` | 叫声钩子：`bed`/`bedLevel`（呼噜、喘气）、`greet`、`tap`、`happy`、`grumble`、`angry`、`prickled` |
| `spiky` | 扎手：按压、逆刺、摩擦时疼痛累积，满了手缩回、发抖。血留在物体上（`PhotoSkin.paintStain`，随网格形变）：落点有血滴，带血的手指继续摸会拖出变淡的血痕；手离开物体、悬在地面上方时会不时滴血到地面（`drips`，约 15 秒止血）。切换物种/毛色时全部清除。不放"叮"之类的提示音，叫声也不要用带音高的方波（听起来像电子音） |
| `icon` | 头像取自第一种毛色图片的正方形区域 `[x, y, 边长]` |

- **画布分层**：舞台里叠三层 canvas，由浏览器合成——背景（2D）、动物（共享的 `GLLayer`，WebGL2）、前景（2D：手、粒子、`drawOver`）。`draw()` 里调用 `GLLayer.get().begin(v)` 后画网格即可。需要每帧动的背景（水面 `WaterPlane`）也画在 GL 层最底下：2D 图案填充每帧全屏重采样两次，实测会掉帧。**不要**把 GL 画布 `drawImage` 到 2D 画布：每帧都要同步 GPU，实测帧间隔从 16.7 ms 掉到 21–23 ms。
- **`PhotoSkin`**（`src/engine/gl/skin.ts`）：照片贴在网格上。每帧写顶点的 `px/py`（世界坐标）和 `light`（每顶点两个值：`shade` 凹陷/隆起明暗，`trail` 顺毛/逆毛光泽），再 `commit()`。`stroke()` 更新炸毛场（逆毛时毛尖被掀起，按 `settle` 秒落回）。
- **`SkinPress`**（`src/engine/skinPress.ts`）：手掌接触形变，手感的核心。包括剪切弹簧（皮肤被手拖着走、停手后弹回）、接触斑压缩、外圈鼓起、前方皮褶、按久托起、前半身跟随，以及短暂的光泽和梳痕。物种只需提供每个顶点的 `travel`（头骨上皮肤滑得少）、`chest`、`head` 权重和毛流方向，并在 `update()` 里传入接触斑（中心、轴向、大小、压力、指腹）。长度系数按参考单位 `U` 换算（猫用 1150 图片像素）。
- **动物自己不动**：除了呼吸，不做转头、甩尾、伸爪等自主动作。反应靠接触形变和声音。
- **照片手**：`Hand.photo = { img, ax, ay, scale }`，锚点放在掌心受力中心，这样指针指哪儿就按哪儿。`hand.photoPoint(px, py)` 把手图像素换算成世界坐标（算指腹位置用）。手臂和影子在第一次绘制时按设备像素预渲染成缓存，运行时不用 `shadowBlur`。

## 6. 调试与验证

- 一键试玩：双击根目录的 `打开游戏.bat`（检查 Node.js 和依赖，dev server 已开着就只打开浏览器）。
- 开发服务器：`npx vite`（默认端口 5188；本机 `[::1]:5173` 被别的项目占用，所以用 `127.0.0.1`）。另开一份时用 `npx vite --port <端口>`。
- 直接打开某个物种：`http://127.0.0.1:5188/?pet=<id>&v=<变体>`。
- 截图与手势脚本：`node tools/play.mjs <脚本.json> <输出目录>`。脚本格式见文件头注释，坐标是世界坐标；`glide` 按真实时间移动（约 60fps），`sweep` 在页面内移动且不阻塞（用来在移动中途截图），`shot` 可按世界坐标裁剪。脚本里可设 `"url"`。
- 帧率：`window.__pet.perf` 是最近若干帧 `step`、`render`（CPU 毫秒）和帧间隔 `frame` 的平均值。只看 CPU 时间会漏掉 GPU 同步开销，判断掉帧要看帧间隔；测量时最好在页面内用 `requestAnimationFrame` 合成指针事件，避免 CDP 输入本身的干扰。
- 页面报错：`node tools/page-errors.mjs <url>`。
- 浏览器自动化遵守 [浏览器自动化建议](浏览器自动化建议.md)：通过 `tools/lib/launch-browser.mjs` 启动配套 Headless Shell。
- `window.__pet` 是 `App` 实例，可在脚本里 `eval` 读取状态，例如 `window.__pet.joy`。
